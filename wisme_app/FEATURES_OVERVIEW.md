# 🎯 Wisme Features Overview

*Complete feature breakdown for the AI-powered microlearning platform*

---

## 🧠 **Core AI Features**

### **🔍 Intent Detection Engine**
- **Smart Topic Analysis** - Understands vague queries like "dogs" or "productivity"
- **Context Clarification** - Asks follow-up questions to pinpoint user intent
- **Category Mapping** - Routes topics to appropriate content categories
- **Learning Goal Detection** - Identifies whether user wants theory, practice, or stories

### **🎯 Smart Categorization System**
- **9 Content Categories** - Technology, Business, Psychology, Science, Creativity, Self-Growth, History, Skills, Career
- **4 Knowledge Levels per Category** - Each tailored to category type (e.g., Business: Fundamentals, Case Studies, Growth Strategy, Bit of Everything)
- **36 Total Learning Paths** - Comprehensive coverage for any topic
- **Dynamic Level Adjustment** - AI suggests optimal difficulty based on user background

### **🤖 Personalized Journey Creation**
- **Dynamic Curriculum Builder** - Creates structured learning paths from modular content
- **Adaptive Content Assembly** - Combines existing blocks with new generated content
- **Progress-Aware Planning** - Builds on previous knowledge and avoids repetition
- **Flexible Journey Length** - 3-day quick dives to 30-day mastery programs

## 🗃️ User Learning Database Schema
- **UserBlock Table** - (UserID, BlockID, Status, FirstPlayed, LastPlayed, PlayCount, JourneyContext)
- **Block Library** - (BlockID, AudioFile, Transcript, Tags, Category, Difficulty, Duration, Prerequisites)
- **Knowledge Graph** - (UserID, ConceptID, MasteryLevel, LastReviewed, DecayPrediction)
- **Learning Sessions** - (SessionID, UserID, BlocksPlayed, EngagementScore, CompletionRate)

### **🔄 Smart Block Reuse Logic**
- **Duplicate Detection** - AI identifies when user has already learned a concept
- **Contextual References** - "Remember when we covered X? Now let's see how it applies to Y..."
- **Progressive Building** - Only serves advanced blocks if prerequisites are met
- **Intelligent Skipping** - Skips redundant content but maintains narrative flow
- **Cross-Journey Synthesis** - Connects learning across different topic journeys

### **🔍 Personal Knowledge Search**
- **Transcript Search** - Semantic search across all consumed content
- **Concept Retrieval** - "What did I learn about growth strategies?" finds relevant blocks
- **Learning Timeline** - Chronological view of knowledge acquisition with context
- **Knowledge Decay Modeling** - Predicts when concepts need reinforcement review
